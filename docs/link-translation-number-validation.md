# 링크 분석: 외국어 수량 검증 수정 (2026-09-19)

## 실제 실패 기록

대상: https://www.instagram.com/reel/DW8tMKyiTxO/

이 URL로 한정한 읽기 전용 조회에서 저장된 작업의
`TRANSLATION_NUMBER_CHANGED` 실패를 확인했다. Bright Data 수집, 힌디어 전사(18구간),
최초 번역 및 보정 번역의 공급자 요청은 모두 성공했다. 번역 결과 자체는 저장되지 않아
실제로 어떤 번역 구간이 차단됐는지는 단정할 수 없다.

저장된 원문에는 숫자로 적힌 99.9%, 254와 말로 표현한 five-in-one, 한 병,
두 달 등의 수량이 함께 있다. 기존 검증은 ASCII 숫자 목록의 일치만 검사했다.
따라서 말로 표현한 수량을 올바르게 5-in-1, 1병, 2개월로 번역해도 새로운 숫자로
간주해 거절한다. 이 오탐 조건을 실제 원문의 수량 패턴으로 재현했다.
반대로 문자가 유지된 채 수량/단위가 달라지는 경우는 숫자 목록만으로 잡을 수 없다.

## 수정 범위

- Creator Studio 링크 추출의 `link-import.js` 및 관련 테스트/문서만 수정.
- 언어별 숫자 단어 사전이나 특정 URL 예외를 사용하지 않는다.
- 숫자로 적힌 원문은 자리표시자로 보호한다. Unicode 십진 숫자도 포함한다.
  누락·중복·다른 구간으로의 이동을 코드로 차단한다.
- 원문에 말로 표현된 수량이 번역에서 숫자가 되는 것은 그 자체로 오류가 아니다.
  별도 구조화된 모델 검증에서 모든 구간의 수량·횟수·기간·가격·단위·비율·제품명
  의미를 대조한다. 원문과 번역의 실제 부분 문자열을 근거로 요구한다.
- changed/uncertain, 누락된 구간, 잘못된 id, 실제 문장에 없는 근거는 승인하지 않는다.
  이 검증은 모델의 의미 판단을 포함하므로 모든 언어의 정확성을 보증하지 않는다.
- 단순 자리표시자 복사 오차만 제한적으로 복구한다. 문장 다른 곳의 숫자를 임의로
  삭제해 검증을 통과시키지 않는다.
- 통상 번역 1회 + 의미 검증 1회. 실패하면 보정 1회 + 의미 검증 1회로 제한한다.
  최대 OpenAI 4회이며 기존 provider 예산·서킷브레이커를 그대로 거친다.
  provider 예산/네트워크 오류에 대해 추가 번역을 실행하지 않는다.
- `translationV2` checkpoint로 이전 숫자 검증을 거친 번역 checkpoint와 구분한다.
  기존 transcript checkpoint는 재사용한다. 완료된 DB 레코드를 소급 변경하지 않는다.
- 기존 /analyze, writer, 계정 추천 필터, 로그인, 저장, PDF는 수정하지 않는다.
