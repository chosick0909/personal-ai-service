# 계정 추천 공통 선별 기준 — 사용자 확정 2026-09-20

이 문서는 살림/인테리어 44개 목록에 대한 사용자 승인과, 다른 카테고리에 재사용할 기준이다.
다른 카테고리를 지금 수집하라는 승인은 아니다. 사용자가 **추가 수집 중단**을 지시했다.
추가 유료 호출 없이 코드·검수 데이터 커밋/푸시만 진행한다. 배포·운영 DB import는 별도 작업이다.

## 모든 카테고리에 유지할 조건

1. 국내에서 활동하고 한국 이용자에게 적합한 일반인 개인 크리에이터. 한국 이름이나 한국어만으로 국내 활동을 추정하지 않는다.
2. 팔로워 최소 10,000명. 1만 미만 선택지는 없으며 any·캐시·기존 카탈로그에도 적용한다.
3. 날짜순 최근 고유 릴스 12개의 **중앙값 10,000회 이상**. 12개 날짜·조회수가 모두 확인되어야 하며 고정/대박 게시물로 표본을 대체하지 않는다.
4. 별도로 실제 500,000회 이상 조회 게시물 근거가 있어야 한다. 한 편의 흥행만으로 계정 전반의 품질을 인정하지 않는다.
5. ordinaryCreator=true, accountType=individual_creator, productionLevel=personal 또는 semi_pro. false/null/unknown/professional·필수 근거 누락은 추천에서 제외한다.
6. 연예인·전업모델·MCN/소속사·공식 브랜드·미디어·리포스트·고비용 전문 제작을 제외한다. 외모는 판단하지 않는다.
7. 본인 경험·사용법·리뷰·전후 비교처럼 교육생이 일상 공간과 스마트폰으로 재현할 수 있는 콘텐츠를 우대한다.
8. 공개 수익화 근거가 없으면 35점 감점하지만 그 사실만으로 제외하지 않는다. 근거를 추측해 채우지 않는다.

## 카테고리별 검수 절차

- 공통 수치/품질 조건은 그대로 유지하고 검색 주제와 검수 대상 분야만 바꾼다. 살림 키워드를 다른 분야 검색에 강제로 넣지 않는다.
- 최근 12개 게시물 전반이 선택 분야를 참고하기 좋아야 한다. 프로필의 분야명·상품 하나·흥행 한 편만으로 분류하지 않는다.
- 살림 목록에서는 요리 레시피/식품 판매, 육아, 뷰티 중심 계정을 보류했다. 이 계정이 다른 분야에서 자동 승인되는 것은 아니다.
- 중앙값과 함께 12개 개별 조회수·최저값·1만 미만 개수·각 게시물 URL을 제시한다. 반복 공구/유사 게시물은 검수 메모로 표시하고 실제 콘텐츠 폭을 확인한다.
- 조회수·일반인 여부·국내 활동·제작 수준·수익화 근거를 먼저 확인하고 5~10개씩 사용자에게 보여준다. 사용자 승인 전에는 reviewedByOperator=false다.
- 카탈로그는 명시적으로 승인된 항목만 별도 import한다. 기존 카탈로그/Redis도 새 품질 기준과 30일 유효기간을 통과해야 한다. 자동 수집으로 DB 카탈로그를 갱신하지 않는다.
- 수량을 맞추려고 기준을 낮추거나 unknown을 true로 바꾸지 않는다. 검색 원후보·자동 심사 통과·운영자 승인 수를 구분한다.

## 승인된 살림/인테리어 기준 사례

사용자는 바이 미룸·호하우스를 좋은 방향으로 평가했고, 2026-09-20 최종 44개 목록에
“내가 원하던 리스트가 딱 이거잖아”라고 전체 승인했다. 35개 카테고리 보류 항목은 승인 대상이 아니다.
승인 데이터: [home-2026-09-20.reviewed.json](../backend/catalog/home-2026-09-20.reviewed.json).
수집일은 2026-09-19 그대로 유지한다. 승인/커밋일을 검증일로 덮어써 유효기간을 연장하지 않는다.
예: bymiroom, _____ho.house, remignon_salrim, wiz_home_, luv_d.m.s.

현재 승인 44개 / 추가 검수 대기 0개. 60개는 달성하지 않았으며 사용자 지시로 수집을 중단했다.
규모별 1만~5만 6개 / 5만~20만 30개 / 20만 이상 8개. 얼굴 비공개 구간 등 빈 구간은 그대로 보고한다.
카테고리당 60개와 20/25/15 배분은 운영 가설이며 모든 필터 교집합의 결과 수 보장이 아니다.

## 비용·실행 기록

살림/인테리어만 US$30 상한을 승인받았다. 보수적 정산 추정 US$27.752, 잔여 US$2.248이며
실제 청구서 미확인이다. 다른 카테고리에 이 US$30 승인을 전용하지 않는다.
새 유료 실행 전 예상 호출·비용·상한을 제시하고 해당 실행 승인을 받는다.
기존 일일 한도/서킷브레이커 및 누적 지출을 유지한다. 저장한 접수 ID와 데이터를 재사용한다.
조건·운영 절차는 [품질 심사 문서](reference-accounts-quality.md), 목표 구성은
[풀 구성안](reference-accounts-pool-plan.md)을 함께 참조한다. 과거 진행 기록과 충돌하면 이 최신 사용자 확정 기준이 우선한다.
