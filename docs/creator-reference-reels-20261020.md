# 추천 계정 릴스 인라인 재생 — 2026-10-20

## 요청 및 구현
- 계정 추천 결과에 실제 릴스 약 3개를 함께 표시하고 사이트 안에서 재생.
- CreatorTools의 계정 설명 앞에 ReferenceReels 삽입. 기존 게시물 텍스트 링크 목록을 실제 Instagram 게시물 iframe 플레이어 3개로 교체.
- 보관된 exampleMedia에서 확인된 릴스/Video만 사용. 부족할 때 기존 viralMedia를 후보로 사용. 동일 shortcode 중복 제거, 최대 3개, 실제 자료가 없으면 수를 만들어 채우지 않음.
- /reel(s)/ 추천 피드가 아닌 정확한 shortcode의 /p/{shortcode}/embed/를 사용. 이미지·영상 다운로드나 재호스팅 없음.
- 계정별 3개 그리드, 좁은 화면에서는 한 열. 화면 근처에 온 플레이어만 마운트. 자동재생 없음.
- 게시물 임베드의 공개/퍼가기/로그인 제한은 그대로 존중. 항상 원문 링크 제공. timeout/onError 안내는 제공하되 cross-origin iframe onLoad를 재생 성공 증거로 취급하지 않음.
- 기존 50만 이상 조회 증거가 3개와 다르면 별도 원문 링크 유지.
- 신규 추천 응답에 기존 저장 자료의 views/contentType 전달. 소스 날짜·계정 선별·승인·30일 유효기간·사용량 정책은 변경하지 않음. 추가 수집/유료 호출/DB 수정 없음.
