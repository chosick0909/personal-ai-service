# 검증된 추천 계정 풀 규모 제안 — 2026-09-19

사용자가 살림/인테리어 승인 계정 60개 확보를 요청했다. 아래 구간별 배분은 제안이며 현재 확보량을 뜻하지 않는다.
팔로워 1만 미만 구간은 사용자 요청으로 제거했으며 전체 추천 풀의 최소 팔로워도 1만으로 적용한다.
살림/인테리어 한 카테고리의 후보 검수와 수집 효율을 먼저 확인한다.
다른 카테고리 확대와 운영 카탈로그 저장은 아직 승인되지 않았다.

## 목표를 세는 단위

검색 username / 프로필 수집 / 수치 통과 / 국내·일반인 심사 통과 / 운영자 승인 계정을 구분한다.
아래 목표는 **검증 유효기간 30일 내이고 새 품질 기준을 통과한 운영자 승인 계정** 수다.
이미 보관한 전체 행 수 또는 검색에서 한 번 찾은 계정 수를 풀 규모로 보고하지 않는다.

## 카테고리당 규모

- 첫 품질 검수: 5~10개를 먼저 제시하고 사용자의 평가를 받는다.
- 초기 운영 목표: 60개. 단일 주요 필터에서도 12개 정도 선택지를 주려는 시작 가설이다.
- 운영 후 확대: 자주 선택하는 필터 교집합에 실제 일치 계정이 5개 미만이면
  그 구간을 우선 보충한다. 사용량과 통과율을 보고 100~120개까지 확대 여부를 결정한다.
- 60개 확보나 모든 필터 조합의 12개 보장은 아니다. 희소 구간을 채우려고 품질을 낮추지 않는다.

| 구분 | 카테고리당 60개 풀의 구성 목표 |
| --- | --- |
| 팔로워 1만~5만 | 20개 |
| 팔로워 5만~20만 | 25개 |
| 팔로워 20만 이상 | 15개 |
| 얼굴 노출 / 비노출 / 혼합 | 각각 약 20개, 실제 수요에 따라 조정 |
| 말하기 / 사용법 / 브이로그 / 전후 비교 / 리뷰 / 텍스트 | 각 형식 최소 12개를 목표로 하되 동일 계정 복수 분류 허용 |
| 최근 7일 활동 | 30개 이상 목표 |
| 최근 30일 활동 | 50개 이상 목표 (7일 활동 계정 포함) |
| 최근 90일 활동 | 전체 60개 (30일 활동 계정 포함) |
| 국내 활동·한국어 수용자 적합성 | 전체 풀에 대한 공통 조건, 언어별 별도 할당 없음 |

필터별 수량은 더하지 않는다. 한 계정이 팔로워 구간·얼굴 유형·여러 콘텐츠 형식을
동시에 충족한다. 3개 팔로워 구간 × 3개 얼굴 유형 × 6개 콘텐츠 형식만으로도
54개 교집합이 생기므로, 60개 풀로 모든 교집합을 충분히 채울 수는 없다.
빈 구간은 그대로 표시하고 이용자가 자주 고르는 조합부터 보강한다.

현재 추천 코드에서 팔로워와 품질 수치는 하드 조건이며 얼굴·형식·최근 활동·언어
선호 일부는 점수 및 완화 안내로 처리된다. 따라서 **화면 결과 수**가 아니라
선택한 필터에 실제로 일치하는 승인 계정 수를 운영 지표로 삼아야 한다.
이 문서로 필터의 동작을 변경하지는 않는다.

## 비용과 확보 수는 별도

현재 12개 시딩 카테고리에 각각 60개를 목표로 하면 총 720개 카테고리 등록이며,
여러 카테고리에 적합한 동일 계정이 있으므로 고유 계정 720개를 뜻하지 않는다.
총 US$120 승인으로 이 목표를 달성할 수 있다는 보장은 아직 없다.

필요 원후보 수 = 목표 승인 수 / 실제 승인 통과율.
예를 들어 20%가 승인된다면 60개를 얻는 데 약 300개 원후보가 필요하다.
통과율은 아직 측정하지 않았으므로 예시 수치를 예산 예측의 사실로 사용하지 않는다.
2026-09-19 사용자가 살림/인테리어에 한해 US$30 상한을 명시 승인했다.
다른 카테고리는 기존 US$10 상한과 별도 확대 승인 조건을 유지한다. 실제 통과율·결측률·1승인 계정당 비용을 본 뒤
수량/예산 확대를 논의한다. 숫자를 맞추기 위한 조건 완화나 자동 승인은 없다.

검수 대기 36개이며, 규모별 6/30/8개(1만~5만 / 5만~20만 / 20만 이상)다.
