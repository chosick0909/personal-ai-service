# Creator Studio 작업 시 유지할 사용자 결정

- reference-accounts를 변경하거나 다른 카테고리를 수집하기 전에 `docs/reference-accounts-policy.md`를 읽는다(저장소 루트 기준).
- 국내 일반인·팔로워 1만 이상·최근 릴스 12개 중앙값 1만 이상·50만 조회 근거·운영자 승인/30일 유효기간을 유지한다.
- 2026-09-20 사용자는 살림/인테리어 44개 목록을 승인하고 추가 수집 중단을 지시했다. 자동으로 수집을 재개하지 않는다.
- 계정 수집 비용 승인은 링크 분석/다른 카테고리 호출 승인으로 전용하지 않는다. 외모를 평가하지 않는다.
- 링크 분석 번역 검증은 `docs/link-translation-number-validation.md`를 참고한다. 모의 회귀 통과와 실제 API 재검증을 구분한다.
- writer, /analyze, 로그인·쿠폰·저장·PDF 및 무관한 Creator Studio 기능으로 수정 범위를 확대하지 않는다.
