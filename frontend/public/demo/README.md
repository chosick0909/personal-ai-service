# Editor sample

`editor-sample.mp4` is the CC0 flower video provided by MDN interactive examples:
https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4

`editor-sample.jpg` is a frame from that video. These local assets allow the
meeting demo to preview actual media without a third-party service at runtime.
They are not a generated analysis result or a student's uploaded media.
